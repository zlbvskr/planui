Бюджет одного WebP: іконка 384×384 до 40 КБ; hero 768×768 до 90 КБ; фонова пляма 1024×1024 до 120 КБ (КБ = 1000 байтів). Це ціль оптимізації, автоматичного обмеження в збірці немає.
Фактична сумарна вага: 10,184,100 байтів. Усі 44 WebP перевищують цей бюджет; ресурси потребують окремого погодженого стиснення.

Додавання: підготуй WebP із прозорим фоном та узгодженим світлом зверху зліва; перевір розмір і вагу. Поклади в каталог як `<ім’я>.webp`, `hero-<ім’я>.webp` або `blob-<колір>.webp`. `ArtIcon` підхоплює іконку через glob; для псевдоніма онови `resolveArtCandidateNames` у `src/ui/art.tsx`. `HeroArt` приймає ім’я без `hero-`; фоновий файл підключи в CSS. Додай рядок сюди, виконай `npm run lint`, `npm run build`, `npm run check:dist` та перевір показ на 390 px. Перевірка збірки контролює включення WebP у precache.
