# PLANUI

Україномовний локальний PWA-планувальник: завдання, звички, календар, зміни, проєкти, цілі, сфери життя й бажання. Без облікового запису, бекенду та AI у рантаймі.

Потрібен Node.js ≥22.12. Встановлення: `npm ci`; запуск: `npm run dev`, адреса `http://localhost:3000/`.
Перевірка: `npm run lint`; збірка: `npm run build`; перевірка ресурсів: `npm run check:dist`.
Перегляд збірки: `npm run preview`, шлях `/planui/`. GitHub Actions збирає pull request до `main`, а зміни в `main` публікує на GitHub Pages. Базовий шлях задає `BASE_URL`, типовий для збірки: `/planui/`.

Дані: IndexedDB `planui_local_db`, схема 1; початкові налаштування вигляду також у localStorage. Після кешування Service Worker застосунок доступний офлайн. Очищення сховища браузера може видалити дані.
У налаштуваннях можна експортувати ZIP і замінити дані з резервної копії. Імпорт перевіряє вміст і виконує атомарну заміну; локально зберігається до трьох точок відновлення. Зберігайте ZIP окремо від браузера.

Структура: `src/views/` екрани; `src/components/` функціональні блоки; `src/ui/` спільні компоненти; `src/domain/` модель і правила; `src/storage/` IndexedDB та копії; `src/state/` оболонка; `src/styles/` стилі; `src/assets/art/` зображення; `src/demo/` приклади; `src/pwa/` керування PWA.
