# PLANUI

Український офлайн-планувальник PWA: React 19, TypeScript, Vite 8, Tailwind 4. IndexedDB `planui_local_db`, схема 1; hash-навігація; GitHub Pages `/planui/`. Без бекенду й AI у рантаймі. UI та документація українською.

Карта файлів: `src/App.tsx` і `src/main.tsx` запускають застосунок; `src/views/` містить екрани, `src/components/` функціональні блоки, `src/ui/` спільні компоненти, `src/domain/` типи й правила, `src/storage/` транзакції та копії, `src/state/` оболонку, `src/styles/` стилі, `src/assets/art/` арт, `src/demo/` приклади, `src/pwa/` керування PWA.

Документація: [продукт](docs/PRODUCT.md), [дизайн](DESIGN.md), [архітектура](docs/ARCHITECTURE.md), [дані](docs/DATA_MODEL.md), [арт](docs/ART.md). Звіряй твердження з кодом.

- Зберігай поведінку, навігацію, українські тексти й сумісність IndexedDB та ZIP, якщо запит не передбачає їх зміни.
- Не видаляй читання сумісних попередніх форматів: ці дані можуть бути на пристрої власника.
- Видаляй код лише після перевірки використань. Не додавай залежності без необхідності.
- Один файл має одну відповідальність; не вводь обгортки й абстракції без кількох реальних використань.
- Коментарі пояснюють причину. Не зберігай закоментований код, історію змін або TODO без конкретної дії.
- Не змінюй сторонні файли, не розкривай секрети. Перед незворотними діями отримай підтвердження; не публікуй і не надсилай без дозволу.
- Після кожного завершеного підкроку виконуй `npm run lint` і `npm run build`, створюй окремий коміт.
- Фінальна перевірка: `npm run lint`, `npm run build`, `npm run check:dist`; запуск `npm run dev` без помилок і попереджень застосунку.
- Для змін інтерфейсу використовуй `node scripts/shot.mjs <екрани>` на ширині 390 px, результати в `qa/before/` і `qa/after/` через `PLANUI_QA_OUTPUT`. Непередбачена видима різниця є помилкою.
