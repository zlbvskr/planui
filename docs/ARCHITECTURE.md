# Архітектура

React 19 + TypeScript, Vite 8, Tailwind 4. `src/main.tsx` монтує `App.tsx`; стан оболонки й обробку hash-навігації тримає `App.tsx`, а `src/state/shellStore.ts` визначає типи, контексти та розбір маршруту. Серверної частини немає.

| Шлях | Відповідальність |
| --- | --- |
| `src/views/` | Екрани сьогодні, календаря, проєктів, звичок, особистого простору й налаштувань |
| `src/components/` | Оболонка, створення, редактори, таймлайн, проєкти, особистий простір, налаштування, онбординг, PWA |
| `src/ui/` | Спільні компоненти, арт, поля, шторки, стек оверлеїв, рух і візуалізації сфер |
| `src/domain/` | Типи, валідація, час, планування, звички, сфери, бажання, проєкції календаря |
| `src/storage/` | Транзакційний рушій, репозиторії, синхронізація вкладок і резервні копії |
| `src/styles/`, `src/assets/art/` | Стилі й локальні WebP |
| `src/demo/`, `src/i18n/`, `src/lib/` | Приклади даних, українські повідомлення, форматування |
| `src/pwa/`, `public/` | Керування оновленням та встановленням, Service Worker, маніфест, іконки |
| `scripts/`, `.github/workflows/` | Перевірка збірки, знімки, аналіз CSS, GitHub Pages |

UI викликає `PlanuiRepositories`; доменні функції перевіряють записи й інваріанти. `db.ts` створює IndexedDB `planui_local_db`, схема 1, з ключем `id` у кожному сторі. Без IndexedDB фабрика використовує транзакційний рушій у пам'яті. Список сторів і поля: [DATA_MODEL.md](DATA_MODEL.md).

`tabSync.ts` координує вкладки; `dbGeneration` захищає заміну набору даних. `backupService.ts` перевіряє ZIP, метадані, хеші й доменний знімок перед атомарною заміною. `zipCodec.ts` обмежує розміри та шляхи архіву. Читання сумісних попередніх форматів даних збережене.

`SharedEditorHost.tsx` збирає стан форми; `saveEditorItem.ts` виконує збереження. Спільні поля містяться в `components/create/`. Оверлеї використовують `ui/overlayStack.ts` і `ui/sheets.tsx` для реєстрації, фокуса та закриття.

`vite.config.ts` задає `/` для розробки й `/planui/` для збірки та preview, якщо `BASE_URL` не задано. Плагін збірки записує перелік ресурсів і хеші в `dist/sw.js`. CI виконує `lint`, `build`, `check:dist`; публікація в GitHub Pages дозволена лише з `main`, поза pull request.
